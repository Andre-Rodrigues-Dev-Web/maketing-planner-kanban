# PlanFlow — Marketing Planner Kanban

Aplicação React para planejamento de conteúdo de marketing com:

- Quadro Kanban: Ideias, A produzir, Em produção, Agendado e Publicado
- Cadastro e edição de posts de imagem, carrossel, Reels, Story, vídeo e artigo
- Canal, campanha, responsável, objetivo, legenda/roteiro, CTA e observações
- Calendário editorial mensal
- Busca e filtro por canal
- Persistência automática no `localStorage`
- Exportação do planejamento completo em PDF

## Como executar

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite no navegador.

## Gerar build de produção

```bash
npm run build
```
